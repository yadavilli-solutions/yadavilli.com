# Holding-Company Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn yadavilli.com into a three-page holding-company site (home, privacy, terms) styled on basantra.com's tokens, with every retired URL 301-redirecting to basantra.com.

**Architecture:** Hugo keeps building the site; Cloudflare Workers static assets keeps serving it. All old sections, the Insights Worker, the Substack scripts, and the vendored Blowfish theme are deleted. Templates and CSS are rewritten from scratch. Redirects live in `static/_redirects`, which Cloudflare evaluates at the edge, so there is no Worker script.

**Tech Stack:** Hugo 0.161.1 in CI (0.169.0 locally), Cloudflare Wrangler static assets, self-hosted Fontsource woff2 (Newsreader, IBM Plex Sans), Python 3 + Pillow + headless Chrome for favicons and the OG card.

**Spec:** `docs/superpowers/specs/2026-11-05-holding-company-site-design.md`

## Global Constraints

- One commit at the end, message `Rebuild yadavilli.com as a holding-company site`. No per-task commits. No attribution trailers of any kind.
- Do not push.
- Colour tokens exactly as the spec table: light `--stone #f6f5f2 --surface #edebe5 --ink #16181b --muted #55585e --line #d6d2c8 --streak #c9a227 --streak-ink #7a5e00`; dark `--stone #121417 --surface #1a1d21 --ink #e9e7e2 --muted #a6a39c --line #2d3136 --streak #c9a227 --streak-ink #d8b545`.
- Fonts: Newsreader 400, 500, 400 italic for headings; IBM Plex Sans 400, 500, 600 for body. Nothing loaded from a third-party origin.
- Basantra Systems is not named anywhere on the site.
- Home copy is fixed by the spec: eyebrow `Yadavilli Solutions`; h1 `A holding company.` with a gold streak under `holding`; body `Yadavilli Solutions is the legal entity behind a small group of operating businesses. It holds them; it does not trade under this name.`; contact line `For legal, finance, and administrative matters: hello@yadavilli.com`.
- `baseURL` stays `https://yadavillidotcom.yakarteek.workers.dev/`. `infra/` is untouched.
- Work in the repo root `/Users/yakarteek/code/personal/w/yadavilli.com`. Scratch output goes under `/private/tmp/claude-501/-Users-yakarteek-code-personal-w-yadavilli-com/19173db0-14c8-4407-95a6-a3a5dc03b413/scratchpad/`.

```bash

name: Deploy

on:
  push:
    branches: [main]

jobs:
  deploy-cloudflare:
    runs-on: ubuntu-latest
    env:
      FORCE_JAVASCRIPT_ACTIONS_TO_NODE24: true
    steps:
      - uses: actions/checkout@v4

      - name: Setup Hugo
        uses: peaceiris/actions-hugo@v3
        with:
          hugo-version: '0.161.1'

      - name: Build
        run: hugo --minify

      - name: Deploy
        run: npx wrangler deploy
        env:
          CLOUDFLARE_API_TOKEN: ${{ secrets.CLOUDFLARE_API_TOKEN }}

  deploy-aws:
    runs-on: ubuntu-latest
    # Only runs once the AWS target is configured; without the variables the
    # job would fail on every push.
    if: vars.AWS_S3_BUCKET != ''
    permissions:
      id-token: write
      contents: read
    steps:
      - uses: actions/checkout@v4

      - name: Setup Hugo
        uses: peaceiris/actions-hugo@v3
        with:
          hugo-version: '0.161.1'

      - name: Build
        run: hugo --baseURL "https://${{ vars.AWS_SITE_DOMAIN }}/" --minify

      - name: Configure AWS credentials
        uses: aws-actions/configure-aws-credentials@v4
        with:
          role-to-assume: ${{ vars.AWS_DEPLOY_ROLE_ARN }}
          aws-region: us-east-1

      - name: Sync to S3
        run: aws s3 sync public/ "s3://${{ vars.AWS_S3_BUCKET }}" --delete

      - name: Invalidate CloudFront cache
        run: aws cloudfront create-invalidation --distribution-id "${{ vars.AWS_CLOUDFRONT_DISTRIBUTION_ID }}" --paths "/*"
EOF
```

// Theme toggle. The inline script in head.html applies the saved choice before
// first paint; this file only handles clicks on the toggle.
(function () {
  var root = document.documentElement;
  var button = document.querySelector('[data-theme-toggle]');
  if (!button) return;

  function current() {
    var forced = root.getAttribute('data-theme');
    if (forced === 'light' || forced === 'dark') return forced;
    return window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';
  }

  function label() {
    button.setAttribute(
      'aria-label',
      current() === 'dark' ? 'Switch to light theme' : 'Switch to dark theme'
    );
  }

  button.addEventListener('click', function () {
    var next = current() === 'dark' ? 'light' : 'dark';
    root.setAttribute('data-theme', next);
    try { localStorage.setItem('theme', next); } catch (e) {}
    label();
  });

  label();
})();

#!/usr/bin/env python3
"""Generate the favicon set and the Open Graph card.

Source of truth: static/img/brand/logo-mark.svg (the Y) and the fonts in
static/fonts. Everything under static/img other than the brand folder is derived.

Rasterizing goes through headless Chrome, so there is no cairo dependency.

Run:  uv run --with pillow python scripts/generate-brand-assets.py
Env:  CHROME  path to a Chrome/Chromium binary (defaults to the macOS app)
"""

import os
import re
import subprocess
import tempfile
from pathlib import Path

from PIL import Image

ROOT = Path(__file__).resolve().parent.parent
BRAND = ROOT / "static" / "img" / "brand"
OUT = ROOT / "static" / "img"
FONTS = ROOT / "static" / "fonts"

CHROME = os.environ.get("CHROME", "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome")

STONE = "#f6f5f2"
INK = "#16181b"
MUTED = "#55585e"
STREAK = "#c9a227"


def mark_path() -> str:
    return re.search(r'<path d="([^"]+)"', (BRAND / "logo-mark.svg").read_text()).group(1)


def icon_svg(rounded: bool = True) -> str:
    """Ink tile with the Y in stone. Reads the same on light and dark tabs."""
    radius = 28 if rounded else 0
    # The mark is 52 x 50; scale 1.3 fills the 128 tile with even margins.
    scale = 1.3
    tx = (128 - 52 * scale) / 2
    ty = (128 - 50 * scale) / 2
    return (
        '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 128 128">'
        f'<rect width="128" height="128" rx="{radius}" fill="{INK}"/>'
        f'<path transform="translate({tx:.2f} {ty:.2f}) scale({scale})" d="{mark_path()}" fill="{STONE}"/></svg>'
    )


def shoot(html: str, dest: Path, width: int, height: int, transparent: bool = False) -> None:
    with tempfile.TemporaryDirectory() as tmp:
        page = Path(tmp) / "page.html"
        page.write_text(html)
        cmd = [
            CHROME, "--headless=new", "--disable-gpu", "--hide-scrollbars",
            "--force-device-scale-factor=1", f"--window-size={width},{height}",
            f"--screenshot={dest}", f"file://{page}",
        ]
        if transparent:
            cmd.insert(2, "--default-background-color=00000000")
        subprocess.run(cmd, check=True, capture_output=True)


def icon_png(size: int, rounded: bool = True) -> Path:
    dest = OUT / f"icon-{size}.png"
    html = (
        "<style>html,body{margin:0;background:transparent}svg{display:block;"
        f"width:{size}px;height:{size}px}}</style>{icon_svg(rounded)}"
    )
    shoot(html, dest, size, size, transparent=True)
    return dest


def og_card() -> None:
    body = (FONTS / "ibm-plex-sans-latin-600-normal.woff2").as_uri()
    display = (FONTS / "newsreader-latin-500-normal.woff2").as_uri()
    html = f"""<style>
@font-face{{font-family:Plex;src:url({body});font-weight:600}}
@font-face{{font-family:Newsreader;src:url({display});font-weight:500}}
html,body{{margin:0;width:1200px;height:630px;background:{STONE};color:{INK}}}
body{{display:flex;flex-direction:column;justify-content:center;padding:0 112px;box-sizing:border-box;font-family:Plex,system-ui,sans-serif}}
.brand{{display:flex;align-items:center;gap:22px;font-size:34px;font-weight:600;letter-spacing:-0.01em}}
.brand svg{{width:40px;height:40px;display:block}}
h1{{margin:72px 0 0;font-family:Newsreader,Georgia,serif;font-weight:500;font-size:112px;line-height:1.05;letter-spacing:-0.01em}}
.s{{position:relative;display:inline-block}}
.s svg{{position:absolute;left:-0.04em;bottom:-0.1em;width:calc(100% + 0.08em);height:0.24em;color:{STREAK}}}
p{{margin:40px 0 0;font-size:30px;line-height:1.3;color:{MUTED};font-family:Plex,system-ui,sans-serif;font-weight:600}}
</style>
<div class="brand"><svg viewBox="0 0 52 50"><path d="{mark_path()}" fill="{INK}"/></svg>Yadavilli Solutions</div>
<h1>A <span class="s">holding<svg viewBox="0 0 200 12" preserveAspectRatio="none"><path d="M3 9C50 5 110 7 197 3" fill="none" stroke="currentColor" stroke-width="4" stroke-linecap="round"/></svg></span> company.</h1>
<p>hello@yadavilli.com</p>"""
    shoot(html, OUT / "og-default.png", 1200, 630)


def main() -> None:
    (OUT / "favicon.svg").write_text(icon_svg())

    sizes = {16: "favicon-16x16.png", 32: "favicon-32x32.png", 180: "apple-touch-icon.png",
             192: "android-chrome-192x192.png", 512: "android-chrome-512x512.png"}
    for size, name in sizes.items():
        tmp = icon_png(size, rounded=size not in (180,))
        tmp.replace(OUT / name)

    Image.open(OUT / "favicon-32x32.png").save(OUT / "favicon.ico", sizes=[(16, 16), (32, 32)])
    og_card()
    print("favicon set and og-default.png written")


if __name__ == "__main__":
    main()
EOF
